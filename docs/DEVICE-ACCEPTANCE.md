# 完整使用过程的真机验收

在正式谱库打开 **Reader settings → Device acceptance**。底部原有版本信息
仍显示 App 版本、构建号、代码提交和源码是否有未提交修改。
本功能在 App 内记录人工观察，不会自动宣称真实 Pencil 或排练体验通过。

## 开始一轮验收

1. 确认安装的版本，在验收页填写操作者和 Pencil 型号。设备型号、系统和
   构建来源自动记录。完成验收需要能追溯到干净提交的构建。
2. 点 **Prepare test library**。首次生成需要几分钟、约 270 MB 空间；保持
   App 打开。全部样本由本地生成，不读取个人乐谱。完成后点 **Open test library**。
3. 测试谱库有明确的隔离标识，包含四页练习谱、0/90/180/270 度页面、已有
   裁剪与红色笔迹的作品、120 页 300 dpi 扫描谱，以及跨四部作品的节目单。
   **Exit test library** 返回验收页。测试中的编辑只保存到测试谱库。
4. 新进程打开验收页后，先点 **Verify test library**，核对样本并重新打开它。
   验收记录与测试谱库分别保存；每份记录绑定样本清单的 SHA-256。

测试谱库位于 App Documents 的 `DeviceAcceptance/library-v1`；正式谱库仍使用
原来的存储位置。测试谱库不属于正式谱库备份。**Rebuild test library** 会先归档
当前报告、开始新一轮，再替换测试样本和测试笔迹；适合恢复统一起点。

## 实际执行与填写

- **Input chain · 30 repetitions**：每次实际完成 Pencil 第一笔 → 连续书写 →
  Done → 点击已有笔迹的位置 → 翻页 → 返回 → 再次标注，再单独记录该次结果。
  检查卡死、误翻页、首笔丢失和跨页串笔迹。30 次均初始为 Not run。
- **Lifecycle and gestures**：逐项测试掌触、双指缩放和平移、快速切换、标注时
  切后台及恢复、锁屏恢复、保存后结束进程并重开、页面与作品间笔迹隔离、旋转和
  裁剪对齐、大扫描谱、跨作品节目单。重开后检查阅读位置和已保存笔迹。
- **30–60 minute rehearsal**：先启动计时，再打开测试节目单演奏，返回后停止
  计时并明确填写观察结果。至少 30 分钟与人工 Passed 缺一不可。
- 出错时填写项目备注和 **Problem reproduction steps**，尽快导出日志。
  本轮出现过的失败会保留，改成 Passed 也不能抹去失败历史；修复后开启新一轮。

计时中结束 App 进程会让本次排练计时标为中断，不把关闭 App 的时间当成连续
排练。后台和锁屏恢复可在同一进程中测试。保存后的记录会在重开时恢复。
构建、设备型号或系统版本发生变化后，旧记录只读；开启新一轮才能记录新环境。
旧记录保存在 `DeviceAcceptance/reports`，不会被新记录覆盖。

汇总结果分为 **Incomplete / Failed / Passed**。缺项、缺操作者/Pencil/样本身份、
时长不足、计时中断、模拟器、无法追溯的构建都不能通过；失败优先显示 Failed。
这些结果表达操作者填报的观察，不是对物理输入质量的自动检测。

## 诊断和导出

诊断默认关闭；准备测试谱库后开启，也可在 Settings 或验收页手动切换。
本地滚动日志最多 **512 条、256 KiB**，后台串行队列约每秒批量写入，进入后台
或导出时刷新。只记录操作类型、状态、页码、节目单项序号、耗时、代码版本和
进程标识：模式切换、加载、笔迹操作边界、保存、输入焦点、生命周期等。
不记录谱名、文件路径、PDF 内容、笔迹坐标或手写内容，不联网。
它是有限的近期线索，不能证明第一笔真实落纸、每一页完整显示或长时间没有故障。

点 **Export report and diagnostics**，通过系统分享页自行存到本机 Files 或发送：

- `report.md`：可读的设备、系统、构建、样本身份、40 项结果、排练和复现步骤。
- `report.json`：同一轮的结构化原始记录。
- `diagnostics.json`：近期诊断元数据，事件包含各自的代码版本和进程标识。

导出包含你主动填写的姓名和备注，不包含样本 PDF 或笔迹文件。分享取消不影响
已保存的报告；日志写入失败会提示，不会改变阅读器保存或输入决策。
报告保存在本机；可与源码备份一起另存，日志可在设置里清空。

这份报告针对完整阅读和排练稳定性。[一键发布验收](VALIDATION-RUNNER.md) 的
`manual-device-template.json` 另含导入、备份等更广的人工检查，仍需按实际情况填写；
本报告可作为其稳定性项目的附件，不能代替未执行的其他项目。

自动测试覆盖状态规则、隔离样本、真实阅读器记录入口、进程重开和界面操作。
真实 iPad、Apple Pencil、掌触、锁屏和 30–60 分钟演奏需要操作者完成。
