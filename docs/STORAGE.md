# 最近删除与本地存储

作品菜单 → **Move to Recently Deleted** 保留原 ID、PDF、笔迹、草稿、裁剪、视图、书签和节目单位置。侧栏或设置 → **Recently Deleted** 显示标题、删除时间和大小，提供 Restore 与手动永久删除。没有自动过期。正常浏览、搜索和演奏队列排除已删除作品；节目单显示占位提示，恢复后原位置重新生效。

设置 → **Storage management** 后台计算文件长度并提供刷新。最近删除是已有分类的子集，不能再次相加；节目单不会重复计数 PDF。实际释放的磁盘空间可能不同。其他占用包括索引、诊断/验收报告、清理记录、备份检查及练习库。统计是一时观测，索引修改会使旧结果失效。

已知优化项：快速连续修改索引或刷新时可能有重叠的后台统计任务。过期结果会被丢弃；尚未加入底层扫描取消机制，实际大谱库响应仍需真机测量。

**Clear cache** 只清理指定 Cache 文件夹和谱库缩略图内存，不触碰 PDF、笔迹、草稿、保留文件和验证/练习副本。已打开阅读器的预览在关闭阅读器时释放。

## 永久清理与中断

确认框展示 1 部作品、节目单引用数量及预计空间。无法在 App 内撤销；恢复依赖之前另存的完整备份。

清理先写入 `.purges/<score UUID>.json`，再持久化待清理状态，然后删除精确匹配 UUID 的 PDF、逐页 drawing 和 draft-commit 文件。确认文件全部消失后更新索引和节目单，最后写入完成记录。记录原子替换并同步到磁盘。任何阶段中断后都可重新打开并重试；待清理项目禁止恢复，因为部分文件可能已被删除。启动只核对状态，不自动删除。

完成记录只保留 UUID、开始时间和完成状态，阻止旧阅读器写回笔迹或旧索引回退复活已永久删除的作品。不要手动移除记录。损坏记录、异常文件类型或重定向目录会拒绝操作并保留文件，不能视为清理成功。

## 旧文件与兼容性

旧版移除后缺少索引的文件，以及不符合已知命名规则的文件，单列为 **Retained files to inspect**。不自动导入或删除，也不能承诺找回原标题、书签或节目单关系。界面最多显示前 100 个文件名，统计仍包含全部。异常目录或链接可导致统计失败，界面明确显示错误并允许刷新。

当前索引版本 **2**；版本 1 自动补全未删除状态，下一次保存写入版本 2，原元数据保留。更高版本拒绝读取。旧 App 会拒绝新索引，不能降级后继续写同一谱库。

备份仍使用 PERCUB01 封装，新清单版本 **2**，仍可恢复版本 1。默认包含最近删除及删除时间，显示数量和归档资产字节数。恢复重分配作品 ID，保留删除状态和映射后的节目单关系。待永久清理项目必须先完成重试，避免产生缺少资产的备份。清理记录、缓存、无索引保留文件不进入可移植备份。

## 验证边界与真机清单

自动测试使用隔离合成谱库，覆盖删除/重开/恢复、重复删除、重复引用、旧索引迁移、备份往返、清理各阶段中断/重试、旧索引回退、旧读写者、未知文件保留和目录重定向保护。

真实 iPad 以下项目尚需人工验收，不能由模拟器代替：

- 记录设备、系统、App 构建号和代码提交，使用隔离练习谱库。
- 对具有笔迹、草稿、裁剪、视图、书签和重复节目单引用的作品，删除后结束进程重开，恢复并逐项目视核对。
- 将包含最近删除的备份导出到 App 目录外，恢复至隔离库，核对删除时间和节目单顺序。
- 核对永久删除的影响说明及清理后的文件；缓存清理前后检查草稿。
- 在大谱库统计期间继续阅读，核对界面响应、刷新与异常提示，保存验收结果。
