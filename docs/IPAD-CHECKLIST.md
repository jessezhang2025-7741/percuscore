# iPad 真机验收清单

以下项目目前均为待执行。使用测试 PDF，不要先导入唯一一份的重要手写标记。

## 构建与启动

- [ ] Xcode 真正编译 iOS target，无编译错误。
- [ ] iPad 安装、首次启动、图标、Files 文件夹可见。
- [ ] 点击原创建谱按钮，打开四页练习谱。
- [ ] 竖屏、横屏、分屏尺寸变化没有控件遮挡或跳页。
- [ ] 普通阅读点击中央隐藏工具栏后，画布延伸到屏幕边缘，没有上下深色背景框；显示浮动工具栏时谱面位置不变。
- [ ] 首次打开四周有大白边的乐谱，不会自动放大；双指缩放并移动到合适位置，后台预览到达时位置不跳动。缩放中心跟随双指所在位置。
- [ ] 第一、二页分别设置不同缩放和位置，来回翻页、拖动页码、关闭重开和退到后台后都独立恢复。Tools > Reset page view 只复位当前页。

## 导入

- [ ] 从本地“文件”选择多份 PDF，导入数量和页数正确。
- [ ] 从已启用的 Google Drive / Dropbox Provider 读取文件。
- [ ] 拖到 Library；拖到 Reader 自动打开第一份；拖到 Setlist 自动追加。
- [ ] 邮件／Files 的“用 Percuscore 打开”可导入 PDF。
- [ ] 原始文件删除或改名后，App 内副本仍可用。
- [ ] 损坏或锁定 PDF 有错误提示，其他已导入文件不受影响。
- [ ] 100 页以上扫描谱的导入、首屏和内存压力。

## 大型扫描 PDF 性能（2026-09-29）

历史模拟器性能测量不包含在本次公开快照中。以下仍需实体 iPad 执行，不能以模拟器数字替代。

- [ ] 用本地生成的 120 页、300 dpi、约 264 MB 灰度／彩色扫描样本，在同一 iPad、系统、竖屏尺寸和编译模式重复五轮。每轮退出测试 App 进程，再从已导入谱库打开；记录动作到首个可见 PDF tile、完整可读纸面时间，注明系统缓存没有清空。
- [ ] 每轮前翻 50 次、后翻 50 次；分别记录状态延迟和可见绘制 P50/P95，以及每轮范围；测试快速连续边缘点击、键盘和缩放状态下翻页。
- [ ] 使用 Instruments 记录打开前、首屏、翻页期间峰值、静置及关闭阅读器后的 App 物理内存，同时观察 RenderServer／GPU。对比基线补丁和最终实现，确认普通阅读没有未使用的半页图片分配。
- [ ] 打开半页模式后测试首次未缓存翻页、低内存提示后首次半页翻页、前后快速连翻、关闭半页／旋转横屏和关闭阅读器；必要两张预览可显示，加载提示结束，退回整页后隐藏图片释放。48 MiB 是可丢弃缓存建议预算，必要活跃图片另行保留，不是 App 内存上限。
- [ ] 在扫描页面添加真实 Pencil 笔迹，设置裁剪和双指视图；连续翻页、内存压力、后台与重开后，笔迹、纸面、裁剪和视图保持对齐，保存状态和手动备份正常。
- [ ] 用一次性测试宿主比较玻璃开／关：核对所有浮动控件位置、面积和可见性一致；以 Core Animation／Time Profiler／GPU 工具测渲染。主线程 display-link 回调间隔不能替代 GPU 测量。实体结果若没有可靠差异，继续保留原生玻璃。
- [ ] 在可用的 iPadOS 17–25 设备检查磨砂材质回退；损坏或加密 PDF 保留现有错误提示，不丢当前页。只使用本地样本，不接入 iCloud／Apple Music。

- [ ] 同一谱库在网格／列表间切换，长标题最多显示两行，页数、阅读位置和收藏标记可见；窄分屏和大字号下控件不互相覆盖。
- [ ] 依次选择 Title、Composer、Last opened、Date added 及正反方向，包含 Study 2／Study 10、空作曲家、未打开作品和相同日期，结果顺序正确。
- [ ] 关闭并重开 App 后保留布局和排序；Recently played 的排序不改动 All scores／Favorites 的排序。
- [ ] 两种布局均可打开、收藏、编辑、导出和移出作品；搜索、收藏筛选、最近阅读与范围书签入口正常。

## 快速跳页

- [ ] 竖屏点击底部红色页码，打开 Go to page；当前页缩略图自动定位并以红框／勾号突出显示。
- [ ] 输入 PDF 实际页码并跳转，最后一页可达；空值、0、超过页数或范围书签之外的页码不能提交。
- [ ] Pages 中的书签／PDF 目录标题可见；Contents 中的书签、范围书签和嵌套乐章目录均可跳转。无目录时已有命名书签仍可使用。
- [ ] 长篇扫描谱连续滚动、重新打开面板及输入远页，缩略图逐步加载且交互正常；检查大型 PDF 内存表现。
- [ ] 标记中打开后关闭面板，撤销／重做历史仍保留；选择页码后原页笔迹保存到原页，目标页笔迹与逐页阅读视图正确。
- [ ] 存储不足或目标笔迹不可读时，原页保留且可继续操作，面板错误提示可读；原生草稿恢复提示在目标页需要时出现。
- [ ] 窄分屏、大字号、键盘弹出／收起、VoiceOver 与深色外观下，页码输入、Go、Done 和列表入口可用。

## 标记与 Crop

- [ ] 竖屏阅读时 Pencil 第一笔完整保留，并自动进入标记模式。
- [ ] 第一笔进入标注模式时谱面不缩放或移动；笔迹继续与音符对齐。
- [ ] 在第一页底半部标注，保存后进行两次半页翻页完整进入第二页；第二页无第一页面的笔迹。连续整页翻页、标注模式保存并翻页、快速前后翻页也测试；退出后重开，各页只保留自己的标注。
- [ ] 禁止手指绘画开启时，掌触无笔迹；手指仍能导航和缩放。
- [ ] 关闭禁止手指绘画后，手指可以写，且不误翻页。
- [ ] 原生悬浮工具栏可选画笔、颜色、宽度、橡皮、套索和标尺；刷新或翻页不重置选中的工具。
- [ ] Done／取消／进入演奏／关闭阅读器后原生工具栏消失；重新标注、恢复前台后正常显示。
- [ ] 每笔 Undo / Redo 正确，擦除动作可撤销。
- [ ] 套索移动、缩放后的笔迹可确认、撤销并重开保持。
- [ ] 标记栏更多菜单的 Cancel annotation changes 恢复打开标记模式前的内容；Done 保留；翻页和退出阅读器先保存。
- [ ] 编辑后退到后台／强制结束 App，再打开同一页能恢复草稿。
- [ ] 非零 MediaBox 原点与 90° / 270° 旋转 PDF 都显示正确。
- [ ] 先写在音符旁，再 Crop 平移、放大、校正、恢复、旋转 iPad，墨迹始终与音符对齐。
- [ ] 双指放大后点边缘直接翻页，返回时仍保留比例和位置；放大后标注依然与音符对齐。

## 演奏

- [ ] 普通阅读调整视图后进入演奏，沿用同一页的比例和位置；演奏中双指缩放、移动，退出或重开后保留调整。
- [ ] 页边写下彩色／浅色 Pencil 标记，进入演奏后标记仍完整可见；旋转 PDF、保存 Crop 后同样测试。
- [ ] 每页保存不同视图后连续翻页，完整页和半页预览都使用对应页的记录；横屏、分屏后比例与相对位置一致。半页过渡中的手势不会改变其他页的记录。
- [ ] 演奏模式移除上下安全区域留白和额外画布边距；内容保持比例，退出后工具栏正常恢复。
- [ ] 演奏模式竖屏、横屏、整页和半页均无上下深色背景框；比例不同产生的剩余空白与白色纸张一致，音符及页边标记完整可见。
- [ ] 关闭半页和横屏分步后快速连续轻点右边缘 3 次前进 3 页，左侧 3 次返回；普通阅读和演奏都测试。
- [ ] 大型扫描 PDF 未缓存时连续点按，界面不中断响应；后台预览到达后保留已调整视图，旧页结果不覆盖当前页。
- [ ] 连续前后翻页后立即退出／切后台，重开到最后一页；跨 Setlist 的每首作品都保留最后位置。
- [ ] 半页预览未缓存时，第一次点击立即上移当前下半页，继续点击无需等待加载结束。
- [ ] 半页／横屏分步开启时连续点击逐次推进；滑动只推进一次，中央双击不误翻页。

- [ ] 左右点按、左右滑动、中心单击隐藏控件、中心双击设置。
- [ ] 横屏先上部、再下部、再下一页；向前向后都正确。
- [ ] 半页第一次显示当前底部＋下一页顶部，第二次显示完整下一页。
- [ ] 分隔线拖动后重开仍保持，每页之间不相互影响。
- [ ] Setlist 中不同页面尺寸的作品交界处不会压扁下一页。
- [ ] Half-page 的上一页操作能够按相反顺序回退。
- [ ] 最后一页不出现空白的半页过渡。
- [ ] 外接键盘左右箭头和空格；如有踏板，再测试其键盘模式。
- [ ] Keep screen awake 只在阅读期间生效，退出后恢复系统息屏。

## 故障恢复

- [ ] Pencil 连续书写时 Saving… 在有待保存内容时显示，停笔后 Saved；控件隐藏／演奏时继续保持谱面展示规则，错误仍有提示。
- [ ] 模拟草稿、确认笔迹、索引或 Crop 写入失败，Save failed 不被其他操作成功覆盖；解除故障后 Retry 将原操作保存到正确页。裁剪失败后取消可恢复已保存基线。
- [ ] 320 点窄窗口、大字号、深色、降低透明度和 VoiceOver 下状态清楚；Retry、标记更多菜单、Done 保持可见且可点击；撤销／重做使用 PencilKit 原生工具面板。
- [ ] Library backup 先取消导出，上次时间不变；完成导出到本地“文件”文件夹 后出现正确时间，重开 App 保留；备份准备失败／恢复也不改时间。
- [ ] 用测试库模拟 backup-export.json 写入失败：备份本身导出成功仍明确说明，旧时间保留；损坏时间文件不会阻止谱库打开。

- [ ] 先备份测试库，再模拟损坏 library.json，能够恢复 backup 并保留损坏文件。
- [ ] 模拟存储不足，保存失败有明确提示，当前笔迹仍保留在内存。
- [ ] 复制整个 Percuscore 数据文件夹或导出完整谱库备份后，PDF、书签、Setlist、Crop、逐页缩放位置和 Ink 可一起恢复。
